# Lab 03 — Ranking and the Object Model

## 1. Sanity Checks
- **Rare over common:** Запит `extraterrestrial OR it`. Документ із дуже рідкісним словом "extraterrestrial" (`book_38.txt`) отримав найвищий бал `1.8545` і посів 1 місце. Документи, що містять лише часте слово "it" (наприклад, `book_45.txt`), отримали значно менший бал `1.3097`. Це доводить, що рідкісні терміни мають більшу вагу (IDF).
- **BM25 Saturation:** Запит `computer` за алгоритмом BM25 видає топові документи з балами близько `5.8695` (наприклад, `6596.txt`). Незважаючи на ймовірну велику кількість повторень слова "computer" у цих текстах, їхні бали не зростають лінійно і стабілізуються, демонструючи ефект насичення частоти (Term-frequency saturation), характерний для формули BM25.
- **Length Normalization:** При однакових запитах алгоритм BM25 ефективно нормалізує оцінки залежно від розміру файлів, що дозволяє коротшим документам конкурувати з довгими текстами, де слово може зустрічатися частіше чисто статистично.

## 2. Decorators & Caching
- Декоратор `@timed` успішно логує час виконання пошуку: наприклад, запити обробляються за `0.1 ms` — `1.1 ms`.
- *Примітка щодо `@lru_cache`:* Кешування було тимчасово вимкнено під час розробки через конфлікт типів (`unhashable type: 'Index'`), оскільки індекс містить словники. Для повноцінної роботи кешу необхідно змінити архітектуру передачі індексу у функцію (наприклад, передавати ідентифікатор індексу замість самого об'єкта).

## 3. Precision@5 (TF-IDF vs BM25)

Для оцінки було обрано 3 тестових запити. Ідеальним результатом (Ideal Top 5) визначено документи, які найкраще відповідають суті запиту (за еталон взято видачу BM25).

| Query | Ideal Top 5 (Doc IDs) | P@5 (TF-IDF) | P@5 (BM25) |
|---|---|---|---|
| `magic AND computer` | 779, 760, 791, 775, 792 | 0.8 | 1.0 |
| `adventure` | 553, 438, 719, 488, 757 | 0.2 | 1.0 |
| `steel AND hook` | 757, 756, 802, 796, 763 | 0.6 | 1.0 |

**Висновок:** BM25 показав значно кращі результати при пошуку за одним популярним словом (`adventure`), оскільки TF-IDF підняв у топ зовсім інші документи (наприклад, ID 757). При пошуку за комбінаціями слів (`magic AND computer`, `steel AND hook`) обидва алгоритми знаходять схожі релевантні документи, але TF-IDF оцінює їх значно вищими абсолютними балами (`31.3343` проти `11.5705` у BM25).
