# Лабораторна робота 1: Ітератори та генератори

## Порівняння використання пам'яті (752 документи)

| Підхід | Час виконання (сек) | Пікова пам'ять (МБ) |
| :--- | :--- | :--- |
| Лінивий (Генератори) | 5.47 | 4.82 |
| Жадібний (Списки) | 0.91 | 6.43 |

**Висновок:** 
Лінивий підхід (`yield`) споживає стабільний мінімум оперативної пам'яті (4.82 МБ), оскільки завантажує і віддає лише один документ за раз. "Жадібний" підхід через `list()` завантажує всі тексти в пам'ять одночасно, тому споживання ОЗП вище (6.43 МБ). 
Аномально швидкий час виконання жадібного підходу (0.91 сек проти 5.47 сек) пояснюється кешуванням файлової системи: під час першого (лінивого) проходу ОС завантажила файли в RAM, тому другий прохід відбувався без звернення до диска.
